# KINAKO PHOTO ALBUM

実家の猫・きなこの写真を、撮影年ごとにたどれるアルバムサイトです。
フレームワークや CMS は使わず、HTML / CSS / JavaScript だけで作っています。

**公開URL**：https://kinako-photo-album.vercel.app/

## まず見てほしいところ

- **年ごとにたどるGallery**：撮影年で絞り込み、年ごとの写真を横スライダーで見られます。スクロールに合わせて、今見ている年に印が付きます。
- **キーボードで使える拡大表示**：写真をTabで選んでEnterで開き、前へ・次へボタンで同じ年の写真を送れます。Escで閉じると、`dialog`を開く前の写真にフォーカスが戻ります。
- **画像の軽量化**：1枚2〜7MBの元写真を、WebPで4サイズに書き出し、`srcset`と`sizes`で表示幅に合う画像を選ばせています。

## ページ構成

| ページ | ファイル | 内容 |
|---|---|---|
| Top | `index.html` | ヒーローと、きなこのプロフィール |

## 使った技術

- **HTML** ：要素の意味に合わせたマークアップ（dl / figure / time / template / dialog）と WAI-ARIA
- **CSS**： Gridによるレイアウト、コンテナクエリ、スクロール駆動アニメーションを使用しています。
- **JavaScript**：ES Modules に分けて、JSON から写真を描画。絞り込み、横スライダー、拡大表示

## 見どころ

### Top

- **ヒーロー画像**：最初の画面を優先して表示するため、遅延読み込みにせず、`fetchpriority="high"`で優先して読み込みます。
- **フォント**：ロゴとプロフィールにWebフォントを使っています。プロフィール用のフォントは使用する文字に絞り、元の約5.1MBから約19KBに減らしました。→ [フォント](#フォント)
- **アニメーション**：スクロールに合わせて、CSSで文字や写真を動かしています。「動きを減らす」設定や未対応ブラウザでは静止表示にします。→ [アニメーション](#アニメーションtop-のプロフィール)
- **レイアウト**：プロフィールの表と写真ボードは、置かれた場所の幅に合わせて列幅や高さを調整しています。コンテナクエリと`cqi`を使い、写真のキャプションが隠れない余白を確保しました。→ [コンテナクエリ](#レイアウトコンテナクエリtop-のプロフィール)

### Gallery

- **年での絞り込み**：年を選ぶ操作に合わせて、ラジオボタンを使っています。絞り込み後は、表示枚数をスクリーンリーダーに通知します。
- **横スライダー**：`scroll-snap`で写真ごとに止まります。前へ・次へボタンは、端に達してもフォーカスを保てるように`aria-disabled`を使っています。
- **表示中の年**：スクロールに合わせて、画面中央にある年に黒点を付けます。絞り込みの選択状態とは別の印で示しています。
- **拡大表示**：`dialog`要素でモーダルを実装し、同じ年の写真を前後に送れます。写真の説明と「10枚中3枚目」のような位置もスクリーンリーダーに伝えます。
- **代替テキスト**：写っている内容を説明する`alt`を付けています。

### 共通

- キーボードで本文へ移動できるスキップリンクを設けています。
- 現在のページを`aria-current`で示し、キーボード操作時にはフォーカスを表示します。
- 「動きを減らす」設定に合わせて、アニメーションと滑らかなスクロールを無効にします。

## フォント

### 方針

本文はシステムフォントを使い、ロゴとプロフィールにWebフォントを使っています。文言が固定されているため、使用する文字だけに絞ってサイト内に配置しました。プロフィール用の4ファイルは、元のTTFの合計約5.1MBから、WOFF2で約19KBになりました。

- `font-display: swap`で、読み込み中も代替フォントで文字を表示します。
- preloadは最初の画面に表示されるロゴだけに指定しています。
- サブセット化したIBM Plex Monoは、予約フォント名を避けて「Profile Mono」に改名しています。

ライセンス文は`assets/fonts/OFL*.txt`に同梱しています。

### 導入前後の計測

ローカル環境でLighthouseのMobile設定を使い、Webフォントの導入前後に各3回計測しました。Performanceの中央値は99から98、CLSはどちらも0でした。

## アニメーション（Top のプロフィール）

スクロールに合わせて「KINAKO」の文字を1文字ずつせり上げ、写真には傾きと上下の動きを付けています。JavaScriptは使わず、CSSで実装しました。

- 文字は親のタイムラインを共有し、`animation-range`をずらして順番に動かしています。
- 写真のめくれと上下移動は、動かすプロパティを分けて指定が競合しないようにしています。
- 「動きを減らす」設定や未対応ブラウザでは、文字と写真を静止表示にします。アニメーション開始時の透明化は`@keyframes`内に限定し、未対応でも写真が隠れないようにしています。

アニメーションが有効な場合、画面の高さによっては、ページを開いた時点で文字が途中までせり上がって見えます。

## レイアウト：コンテナクエリ（Top のプロフィール）

プロフィールは画面幅が64rem（標準設定で1024px）以上になると2列になり、表や写真ボードの幅が狭くなります。そのため、画面幅ではなく、それぞれの部品の幅を基準にレイアウトを調整しています。

- 表は`@container`で、幅に余裕があるときだけ見出し列を広げています。
- 写真ボードは`cqi`で幅に応じた高さを計算し、写真のキャプションが重ならない余白を確保しています。
- 未対応ブラウザ向けには、固定の縦横比を指定しています。

## 制作の進め方とAIの使い方

### 制作の進め方

- HTML / CSS / JavaScriptの実装を見てもらうため、サイト本体にはフレームワークやライブラリを使っていません。
- デザインをいくつか検討し、写真を年ごとにたどれるアルバムの構成にしました。
- 写真はすべて自分で撮ったものなので素材の権利関係を明確にでき、十分な写真量を確保できることから、愛猫の写真を採用しました。

### AIの使い方とAIに任せたところ

主に写真の変換スクリプトの実装、代替テキストの下書き、画面幅ごとの隙間の計測にAIを使いました。

- **写真の変換スクリプト**：WebPへの変換、複数サイズの書き出し、位置情報の除去を要件として決め、実装をAIに任せました。
- **写真の代替テキスト**：AIで下書きを作り、すべて自分で確認しました。
- **アニメーション中の隙間の計測**：目で見て確かめきれないため、AIにPlaywrightで画面幅ごとに計測してもらいました。
